## 📌 프로젝트 개요 (Overview)

본 프로젝트는 **(주)제온스(ZEONS, Inc.)**의 스마트 자산관리 ERP **이지램스 (ezREMS)™**의 56페이지 원본 사업 제안서를 웹 표준 기술을 통해 **고해상도 인터랙티브 프레젠테이션 및 반응형 디지털 문서**로 구현한 프로젝트입니다.

글로벌 부동산 자산관리(PMS) 시장 트렌드부터 실무 운영 프로세스(LM·PM·FM·AM), 10대 유·무형 자산 확장 ERP, 고객사 실증 성공 사례(K 리츠사, 앨리웨이, 제일풍경채, 수광비 정밀과금), SAP FI 및 OpenAPI 엔터프라이즈 연동, 중대재해 안전보건(EASY SAFE) 및 차세대 AI 자산관리 로드맵까지 총 **23개 핵심 슬라이드**로 집약하여 제공합니다.

## ✨ 핵심 기능 (Key Features)

### 1. 🌐 완벽한 4개 국어 다국어 지원 (Full Multilingual Support)
- **한국어 (KO)**: [`index.html`](index.html) - 표준 한국어 원본 에디션
- **영어 (EN)**: [`index_en.html`](index_en.html) - 글로벌 비즈니스 프롭테크 영문 에디션
- **일본어 (JA)**: [`index_ja.html`](index_ja.html) - 일본 자산관리 비즈니스 실무 일문 에디션
- **중국어 (ZH)**: [`index_zh.html`](index_zh.html) - 표준 중국어(간체) 전문 용어 에디션
- **상태 보존형 동기화 엔진**: 상단 GNB의 `[🌐 KO | EN | JA | ZH]` 언어 전환 시, 현재 보고 있던 슬라이드 번호(`?slide=N`)와 뷰 모드(`mode=scroll` or `pt`)가 유지되어 끊김 없는 화면 전환을 제공합니다.

### 2. 🖥️ 혁신적인 듀얼 뷰 모드 (Dual View Mode)
- **슬라이드 PT 모드 (Presentation Mode)**:
  - 16:9 비율의 프레젠테이션 전용 뷰포트
  - 키보드 단축키 지원 (좌우 화살표, Space, PageUp/Down, Home/End, F키 전체화면, M키 목차 등)
  - 슬라이드 페이드 애니메이션 및 하단 실시간 진행률(Progress Bar) 표시
- **스크롤 웹 문서 모드 (Scroll Document Mode)**:
  - 제안서 전체 23개 슬라이드를 단일 반응형 웹 문서 형태로 연속 열람
  - 인쇄(Print) 및 PDF 내보내기에 최적화된 레이아웃

### 3. 🏢 10대 유·무형 자산 확장 ERP 유니버스 (Chapter 6)
부동산에 국한되지 않고 모든 수익형 유·무형 자산을 단일 코어 엔진으로 수용:
1. **주거/레지던스**: 원룸, 실버타운, 코리빙, 청년 임대
2. **상업/리테일**: 쇼핑몰, POS 매출 연동, 변동 수수료
3. **업무시설 (Office)**: 프라임 오피스, 일반 빌딩 자산운용
4. **물류/창고**: 상온·저온 풀필먼트 물류 거점
5. **IT 인프라 (IDC)**: 서버 랙(Rack) 상면, 전력 인프라
6. **추모/안치**: 봉안당 안치단, 묘지 시설 영구 분양/관리
7. **모빌리티**: 렌터카, 오토리스, 정비 이력 통합
8. **구독/렌탈**: 패션 의류, 고가 비품 정기 구독
9. **무형자산**: 소프트웨어 라이선스, 유지보수 계약 ERP
10. **신규 비즈니스 발굴**: 모든 신규 유무형 비즈니스 모델 즉시 수용

### 4. 📊 검증된 엔터프라이즈 실증 사례 (Case Studies)
- **K 리츠사**: 전국 10개 프라임 빌딩 통합관리, 결산 5일 ➔ 2시간 단축
- **앨리웨이 쇼핑몰**: POS 연동 매출 정산, 정산 오류 0%
- **제일풍경채 1,045세대**: 네이버 전자문서 및 카드결제 연동으로 미납률 25% ➔ 6% 극적 감소
- **수광비(수도·광열비) 3단계 자동화**: 복잡한 안분식 및 누진세율 오차 0% 정밀 과금
- **대기업 연동**: MGRV(맹그로브) 코리빙 OpenAPI 및 SAP FI 회계 모듈 연동

### 5. 🛠️ 풍부한 인터랙티브 도구 (Interactive Tools)
- **56P 원본 PDF 슬라이드 갤러리**: 원본 장표 고해상도 썸네일 및 슬라이드 비교 뷰어
- **제안 발표 목차 (Agenda) 모달**: 23개 슬라이드 원클릭 즉시 이동
- **도입 및 제휴 문의 모달**: 원클릭 상담 신청 폼
- **반응형 파비콘(Favicon)**: 16x16, 32x32 공식 브랜드 파비콘 완벽 연동

## ⌨️ 키보드 단축키 안내 (Keyboard Shortcuts)

| 키(Key) | 동작(Action) |
| :--- | :--- |
| **`→` / `Space` / `PageDown`** | 다음 슬라이드 이동 |
| **`←` / `P` / `PageUp`** | 이전 슬라이드 이동 |
| **`Home` / `End`** | 첫 페이지 / 마지막 페이지 이동 |
| **`F`** | 전체화면 모드 토글 (Fullscreen) |
| **`M`** | 제안 발표 목차 (Agenda) 모달 열기 |
| **`G`** | 원본 56P PDF 슬라이드 갤러리 열기 |
| **`Esc`** | 열려있는 모든 팝업 모달 닫기 |

## 💻 실행 및 브라우저 호환성 (Getting Started)

별도의 백엔드 설치나 빌드 과정 없이, 모든 최신 웹 브라우저에서 즉시 실행 가능합니다.

```bash
# 로컬 웹 서버 실행 (Python 3 기준)
python -m http.server 8000

# 브라우저 접속
http://localhost:8000/index.html
```

- **지원 브라우저**: Chrome, Edge, Safari, Firefox 최신 버전
- **기술 스택**: HTML5, Tailwind CSS (JIT via CDN), JavaScript (ES6+ Vanilla), Lucide Icons, Paperlogy Web Font
