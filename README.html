2. 듀얼 뷰 모드 및 핵심 아키텍처

슬라이드 PT 모드 (Presentation Mode)

16:9 비율의 캔버스 뷰포트 내에서 슬라이드 페이드 전환 효과와 함께 발표를 진행할 수 있습니다. 키보드 화살표, 스페이스바, 전체화면(F), 목차(M), 갤러리(G) 등 다양한 단축키와 실시간 진행률 게이지를 지원합니다.

슬라이드 상단 디바이더 구분선 보존으로 장표 명확화
스크롤 웹 문서 모드 (Scroll Document Mode)

23개 슬라이드를 단일 반응형 웹 문서 형태로 연속 스크롤하며 검토할 수 있습니다. 각 섹션이 독립된 박스 형태로 배치되어 인쇄 및 보고서 정독에 최적화되어 있습니다.

스크롤 모드 전용 CSS 격리로 불필요한 구분선 중복 제거

3. CHAPTER 6. 비즈니스 모델 확대 (10대 유·무형 자산)

이지램스는 전통적인 부동산(아파트, 오피스)에 머물지 않고, 단일 코어로 모든 유·무형 수익 자산을 즉시 수용합니다.

01. 주거/레지던스
원룸 · 실버타운 · 코리빙 · 청년임대
02. 상업/리테일
쇼핑몰 · POS 매출 연동 수수료
03. 업무시설 (오피스)
프라임 오피스 · 일반 빌딩 자산운용
04. 물류/창고
상온·저온 풀필먼트 물류 거점
05. IT 인프라 (IDC)
서버 랙(Rack) 상면 · 전력 인프라
06. 추모/안치
봉안당 안치단 · 묘지 영구 분양
07. 모빌리티
렌터카 · 오토리스 · 정비 이력 통합
08. 구독/렌탈
패션 의류 · 고가 비품 정기 구독
09. 무형자산
소프트웨어 라이선스 · 유지보수 계약
10. 신규 비즈니스 발굴
모든 유·무형 신규 비즈니스 즉시 수용

4. 키보드 단축키 안내

단축키 기능 설명 사용 가능 모드
→ / Space / PageDown 다음 슬라이드로 이동 슬라이드 PT 모드
← / P / PageUp 이전 슬라이드로 이동 슬라이드 PT 모드
Home / End 첫 슬라이드 / 마지막 슬라이드 즉시 이동 슬라이드 PT 모드
F 브라우저 전체화면 토글 (Fullscreen) 공통
M 제안 발표 목차(Agenda) 팝업 모달 열기 공통
G 원본 56P PDF 슬라이드 갤러리 모달 열기 공통
Esc 열려있는 모든 모달 팝업 닫기 공통
